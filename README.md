# Emmanuel Cash Flow

Production-ready church cash-flow management built with React, Vite, Supabase PostgreSQL, and Supabase Authentication.

## Local development

1. Copy `.env.example` to `.env.local`.
2. Add the Supabase project URL and anon/publishable key.
3. Run `npm install`.
4. Run `npm run dev`.

Use `npm run build` for the Vercel production build. See `README_DEPLOYMENT.md` for the complete setup and deployment procedure.
